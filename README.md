# AIORI-3-HACKATHON-PROJECTS
This repository will contain the code and resources for the AIORI-3 hackathon that will be developed during the AIORI-3
📌 Project Description
PrivacyShield AI is a cybersecurity and privacy auditing platform designed to detect potential Personally Identifiable Information (PII) exposure in uploaded datasets. It helps users identify sensitive information, assess potential risks, and maintain structured evidence logs through an interactive dashboard.
The platform analyzes uploaded files, detects sensitive data patterns, categorizes findings by risk level, and presents audit results in a visual format. It also aims to support privacy verification and secure data handling through algorithmic validation and evidence tracking.
🎯 Objectives
PII Detection: Identify potentially sensitive information, such as email addresses and phone numbers.
Risk Assessment: Assign risk levels to detected information to highlight potential exposure.
Evidence Logging: Maintain records of detected information for audit and verification.
Interactive Dashboard: Display audit statistics, exposure records, and risk visualizations.
Data Validation: Support verification of specific identifiers using algorithmic checks.
Privacy Protection: Help users identify potential data exposure and improve privacy awareness.
✨ Key Features
📂 Multi-Format File Upload: Supports CSV, TXT, and XLSX files.
🔍 Sensitive Data Detection: Identifies patterns associated with personal information.
📊 Risk Visualization: Displays potential exposure through interactive charts.
📋 Evidence Logs Registry: Records detected data types, risk levels, and audit status.
🛡️ Verhoeff Algorithm Check: Supports validation of identifiers using the Verhoeff algorithm.
🗄️ SQLite Evidence Vault: Designed to store audit evidence and related records.
⚡ Cyber Remediation: Includes a remediation feature intended to support safer data handling.
